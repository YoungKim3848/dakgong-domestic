과목마다 목적이 다릅니다

닥공캠프 한국 스파르타 캠프는 수학을 중심축으로 국어, 영어특강, 수능대비, 선택과목, 관리형 자습, 멘토링까지 입시에 필요한 주요 과목 밸런스를 완벽하게 책임집니다.

핵심과목 수학수업 주중 집중학습 +
  • 상위권 대학 진학을 결정짓는 핵심, 수학의 절대적 학습량을 확보합니다.
  • 개인 맞춤형 분반 — 학년과 상관없이 입소 전 진도와 현재 실력을 정밀 분석해 최적의 반을 구성합니다.
  • 강의형 밀착 시스템 — 개념강의 → 수준별 문제풀이 → 오답 관리 → 반복 학습으로 이어집니다.
  • 선행학습을 위주로 하되, 놓치기 쉬운 현행 학습까지 빈틈없이 연계 관리합니다.
주말특강 국어·영어 전문 특강 +
  • 국어 — 중등부는 문법 체계와 비문학·문학 독해 기초, 고등부는 수능형 출제 패턴 분석과 실전 독해력·시간관리를 강화합니다.
  • 영어 — 수능형 지문 독해법, 고난도 문제 유형, 오답 분석 지도와 모의고사 실전 풀이로 입시 영어 감각을 단기간에 끌어올립니다.
학년별 맞춤 수능 대비 집중반 고2~고3 +
  • 실제 수능 타임 테이블에 맞춘 모의고사 연습 → 심층 해설 → 오답 정리 → 관리형 자습을 반복합니다.
  • 최근 수능을 직접 치러낸 선배들과 실전 학습 루틴, 당일 멘탈관리 조언을 나눕니다. (선배 멘토링 상세는 선생님·멘토 페이지에서 확인하세요.)
목표별 선택 과학 및 사회 선택과목 +
  • 학생이 선택한 수능 탐구 과목 중심으로 개념 정리와 심층 학습을 진행합니다.
  • 개인별 목표 대학 가이드라인에 맞춰 반을 구성합니다. (신청 인원과 운영 상황에 따라 개설 여부가 조정될 수 있습니다.)

CLASS PLACEMENT | 반편성 원칙

학년이 아니라 실력이 반을 정합니다

학년과 상관없이 입소 전 진행해온 진도와 현재 실력을 정밀 분석해 최적의 반을 구성합니다. 같은 학년이라도 선행 정도와 문제 해결 수준이 다르면 서로 다른 반에 배정될 수 있습니다.

PLACEMENT TEST | 배정 기준

반편성은 어떻게 결정되나

입소 전 학부모 상담으로 현재 학교·학년·최근 학습 진도·취약 단원을 확인합니다. 필요하면 자체 테스트를 진행하고, 수업 시작 후에도 실제 이해도와 과제 수행 상태를 확인해 최종 반을 조정합니다.

수학

희망 진도의 이전 1년 과정 테스트 + 희망 진도 과정 테스트. 고등부는 내신형·모의고사형 문제를 모두 확인합니다.

국어·영어
